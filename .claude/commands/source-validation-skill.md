# Source Validation Skill

## Features
- Reliability scoring
- Bias detection
- Relevance filtering

## Instructions
- Check references
- Evaluate author and date
- Highlight trustworthy content

## Constraints
- Avoid unverified info
- Prioritize high-quality sources
