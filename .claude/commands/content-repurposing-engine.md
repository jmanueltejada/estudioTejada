# Content Repurposing Engine

## Features
- Extracts key ideas
- Adapts for platforms
- Maintains tone and clarity

## Instructions
- Analyze original content
- Identify key points
- Rewrite in target format
- Keep consistent tone and readability

## Constraints
- Preserve meaning
- Avoid verbosity
- Format must match channel style
