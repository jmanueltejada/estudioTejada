# Skill Creator

## Overview
Automates creation of AI skills by generating fully structured .md files.

## Output Format
- Skill name
- Description
- Instruction steps
- Constraints

## Instructions
- Accept input goal
- Define role, task, and process
- Output structured .md skill file

## Constraints
- Maintain clarity
- Ensure usability
- Keep instructions specific not generic
